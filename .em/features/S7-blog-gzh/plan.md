### 关键技术点

1. **选帧**：srt 时间轴对齐——逐字稿标「此处该有图」段落 → 取段内时间戳 → ffmpeg `-ss` 精确抽帧 → 落 `source/images/<slug>/`，预览清单人工换帧/删图
2. **文风红线（硬约束）**：外部文风引擎只允许生成初稿；与 STYLE.md 硬规则冲突一律 fallback STYLE.md + em learn humanize 终检——调研结论不改终检体系
3. **md→公众号**：公众号编辑器不吃 md，需内联样式 HTML（开源 renderer 选型或 fallback 自研转换器）；图片走公众号素材库上传
4. **ego 驱动器**：复用 S6 drivers 全套对策（全新 space 名 / rc 判空 / uncaughtException 兜底 / 浮层吃点击 Escape 重试环 / Preferences 手术强杀全家）；登录态失效 handOff 人工扫码
5. **边界红线**：不做 `hexo deploy`（备案期）；不做公众号群发（人工点）；文风不重造轮子
