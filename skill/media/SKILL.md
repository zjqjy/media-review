# media · 自媒体（门面）

一个入口管一条内容的发前发后。本文件只做路由，规程在各子技能里：

```
素材 ──cut──▶ 粗片 + SRT + 逐字稿 ──发布──▶ review ──▶ 复盘报告 ──▶ 写回/改进实验
                └── 逐字稿归档 vault 复盘/逐字稿/，review 直接取（闭环）
```

## 路由

| 用户意图 | 子技能 | 动作 |
|---|---|---|
| 粗剪 / 砍静音 / 压缩素材 / 转录 / 选段 / 有素材要剪 / 还没录想问怎么录 | **cut** | 读 `cut/SKILL.md`（路径相对本技能目录）照做 |
| 复盘 / 看数据 / 到期观察点 / 改进实验核对 / 发完视频看表现 | **review** | 读 `review/SKILL.md` 照做 |
| 剪完接着问数据 | cut → review | 先走完 cut 的归档，再进 review |
| 意图不明 | 问一句 | "要剪素材还是复盘数据？"，别猜着跑 |

子技能目录各自带 `scripts/`，脚本路径以子技能 SKILL.md 内写的为准。两边共用的东西只有一处：vault 路径（cut 归档逐字稿、review 读取）。
