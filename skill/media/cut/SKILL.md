# cut · 剪辑提效（发前粗剪）

素材 → 剪映粗剪草稿（主交付）+ 一进一出分段成片 + 转录稿（逐字稿归档由 post 做）。痛点是"看素材选段"，解法是转录出时间索引后"删句子=剪视频"。**照下面的标准流程表执行，不要临场发挥**；每步都有实测时间预算，超出预算说明走偏了。

## 标准流程（素材就位 → 照表执行）

| 步 | 动作 | 预算 | 要点 |
|---|---|---|---|
| 0 前置 | `python scripts/env_check.py` | 0.3s | 缓存秒过（30 天过期/--force 刷新）；缺重依赖须用户点头才装 |
| 1 机器段 | `python scripts/run_cut.py --init 素材目录...` | 2-3min | 建工作区+全部素材**单批转录一次模型加载**+逐段 scan 落 `.scan.txt`，打印初选交接单 |
| 2 并行初选 | 复制 `scripts/初选代理模板.md` 替换占位符，每大段（>15min 素材）发一个子代理、小段合并，**全部同时发出** | 墙钟=最大段 15-20min | 代理自验锚字后落 `_工具/初选决定_<段名>.json` 碎片 |
| 3 收尾 | `python scripts/run_cut.py --finish 待粗剪... [--order 段1,段2...]` | ≤5min（粗片后台） | 合并碎片→dry→apply→剪映草稿→organize→**srt_cut 后台出 4_粗剪成片 实体粗片存档**（重编码挂机不阻塞）；顺序非序号命名必须 --order |
| 4 复核 | `python scripts/run_cut.py --qa 待粗剪...` | 3-5min | 成片音频快剪→重转录→口癖/重复残留审计（见 QA 甄别） |
| 5 交接 | 草稿+标注轨给用户；粗片存档后台跑着（交接时告知） | 1min | 漏斗数据带时间戳记录 |

短素材（<5min）整期目标线 **10 分钟内**。实测基线：9 段单批转录 2:11；两期（2:12 短 + 75:36 长）一次跑完 29:33。

**特殊入口**：素材全程无口述 → 本流程做不了，如实告知只能人工看片，重点提醒下期口述（认知①）。已有其他渠道转录稿（srt/md）→ 跳过步骤 1 的转录部分，直接从步骤 2 开始。还没录/在规划 → 先讲认知①。

## 初选判断规则（步骤 2 发代理摘抄 + 自己拍板依据）

1. 删三类铁废料：纯语气词条目（嗯/对/好/Ok啊 单字句）、乱码无信息、整段重复
2. **意思重复 → 删前留后**：同一步骤讲多遍（哪怕措辞不同）只留最后一遍；重复范围内**独有内容必须剔除保留**（keep_anchors 防删穿）
3. 口吃、假起头、说半截**保留**（词级洞/标注轨处理）；不因啰嗦删整句——品味判断归用户；拿不准一律保留并写进回复
4. 条目内只修 ASR 错拼不改写口播；全局错拼表 `asr_fixes.json` 自动套用，新错拼模式跨期沉淀进该表
5. 决定 JSON 支持 `annotate: [{"ids": [n..], "note": "逻辑混乱：…"}]`——**语义重复拿不准、逻辑混乱、口吃密集**的段落打标注，jy_draft 自动上标注轨（⚠前缀红字）提示人工精剪
6. 落盘前自验锚字（删除条目含锚、keep_anchors 存在且不在删除表、fixes 子串命中）；select.py --dry 整批把关

**QA 甄别经验**（步骤 4 报告的判读）：成片二次转录的碎片切条多为误报（「我们的」这类残句是 ASR 切条产物）；「选择A | 点CN的都是A」类相邻互补句不是重复；真重复特征=同内容完整讲两遍。口癖残留下限=无停顿连读（转录端孤立呃/嗯已停顿守卫自动挖，两侧≥0.18s 才下刀），连读残留留精剪。

## 关键认知（所有决策的依据）

1. **改造录制习惯比换工具更值**：录屏时同步口述——口述就是时间标记+内容索引。素材全程无口述 → 本流程无从下手，提醒下期口述
2. **工具类内容收藏率比完播率重要**：粗剪保住"清单感"（步骤完整、结论前置、每步可跳读），别为完播砍步骤

## 技术事实（避免重新踩坑）

- **零重编码**：全流程单一原始素材时间轴，转录直吃原素材音频（VAD 跳静音），jy_draft 引用原素材+自带静音细剪。`silence_trim.py` 已退役为可选预览
- **静音细剪边缘 keep=0**（2026-09-20 修）：静音边界是 ffmpeg 实测能量，keep 回退会把每段尾部多咬 0.2s、削掉末字尾音（实测 03 段「获取」）；ASR 词级洞的 keep/pre_roll 不受影响
- **静音检测缓存**：detect_silences 按 文件+参数+mtime 缓存 `.silence.json`，jy_draft/qa/backfill 全场复用
- **转录**：FunASR Paraformer CPU；模型走 ModelScope 国内 CDN——**下模型关 VPN，pip 装包开 VPN**，首跑 ~1.2G
- **词级对齐脆弱**：转录警告"token ≠ 时间戳，按比例兜底"= 词级洞全丢（时间戳失真不可用），必须修完重跑（脚本自动试撇号/连字符合并）
- **剪映陷阱**：剪映运行中拒绝写草稿（防回收站吞草稿），等待重试别 --force；`--draft-folder` 一次性用法不落状态文件
- **字幕排版**（2026-09-20 校准）：白字+黑描边+半透明黑底板（alpha 0.6）；断行 ≤20 显示宽/行（ASCII 词不拆）；末行锚底 y=-0.86、每行上移 0.05；字号 4.3。常量在 jy_draft.py 顶部
- **草稿防覆盖默认不覆盖**（2026-09-20）：管线写完盖 sha256 戳，同名重出时戳对不上（剪映精剪/手工改过）自动落 v2/v3 新名，绝不覆盖用户改动；--force 才原地覆盖
- **自校验**：jy_draft 落盘前比对剪切稿 vs 字幕轨条数，丢条当场列原文；rebase 钳制容差 1.5s（ASR 尾部时间戳普遍滞后 ~0.8s）
- **依赖**：env_check 用 importlib.metadata 查版本，**绝不 import torch/funasr**

## 交接与归档

- **主交付**=剪映草稿（主轨保留段+字幕轨+标注轨+交付两件套）；**粗片存档**：`--finish` 自动后台跑 `srt_cut.py --seq ... --out-dir 4_粗剪成片`（重编码挂机，附对齐字幕 srt）——**交付不能只有草稿**：草稿里删掉的段剪映不进回收站，改坏/误删时实体粗片+原素材是唯一的找回底座（2026-09-20 用户要求）。交接时要告知用户粗片在后台生成、完成后在 4_粗剪成片
- **精剪与字幕解耦**（2026-09-20 用户痛点：草稿里删视频会把字幕轨带歪/剪坏）：用户嫌字幕碍事就出纯视频草稿 `jy_draft.py ... --no-sub`（字幕/标注落 srt 存草稿旁），精剪随便删；定稿导出成片后进 **post** 子技能重出字幕（`post/scripts/final_sub.py`）
- **草稿一经剪映打开即被加密重写，管线读不回**（2026-09-20 实测 draft_content.json 变混淆格式）——所以"读用户改后的草稿重对齐字幕"这条路不存在，一切重出/重对齐都从工作区剪切稿走；草稿删了不可怕，工作区在就能秒级重出
- 标注轨=红色置顶（口吃·重说/🔁重录对/[拆条]/⚠语义重复·逻辑混乱提示），**导出成片前删掉该轨**；加速/BGM/花字全在精剪域（粗剪 1.0x）
- 逐字稿归档**已移到 post**（2026-09-20 用户决定：归档跟成片定稿走，不跟粗剪走）——cut 只产转录稿（3_转录初选/<段>.srt），post 定稿后归档 vault。别在 cut 交接时归档
- **发布后复核三信号**（进 review 时核对）：开头 3 秒流失→查初选是否删伤开头；留存中段尖峰→对照挖洞接缝；完播偏低且平滑→初选删太碎。结论写回当期复核单

## 错误处理

| 情况 | 动作 |
|---|---|
| 转录警告"token ≠ 时间戳，按比例兜底" | 词级洞全丢不可用——已自动试撇号/连字符合并；仍失败看警告里可疑字符 |
| 转录稿里还有口癖没剥 | 看前一字符：分句标点后没剥=bug；无标点连读（无停顿）不硬抠，留精剪 |
| 自校验报"丢 N 条字幕" | 看列出的原文：落在词级洞里的正常（口播已挖掉）；其余是时间戳漂移 |
| QA 报"疑似重复组" | 人工甄别：碎片切条/相邻互补句=误报；同内容完整讲两遍=真重复→qa_backfill 回补删除 |
| QA 揪出"该删没删" | qa_backfill 回补→--finish 重出→再 --qa（一轮 ~10min） |
| 转录重跑后决定索引漂移 | **含重复内容的段禁止 remap 搬决定**（近似重复锚字分不清遍次，会删错遍）——按新稿重判；无重复段可用 remap_decide.py |
| jy_draft 报草稿目录不存在 | 剪映全局设置→草稿位置，--draft-folder 指定（显式用法不落状态文件） |
| 精剪时删视频把字幕轨弄乱 | 预防：用 --no-sub 出纯视频草稿；已乱的两条路——重出草稿（工作区剪切稿还在）或删掉字幕轨，定稿后走 post 子技能重出字幕 |
| 剪映打不开草稿 | 升级 pyJianYingDraft；仍不行退 srt_cut 出粗片+双 SRT 导入 |
| ModelScope 下载慢 | 关 VPN 直连（国内 CDN）；pip 才需要 VPN |
| 技术词识别错 | --hotword 重跑；常见错拼进 asr_fixes.json 沉淀 |
| Git Bash 造测试素材 | 别放 /tmp（Windows Python 路径体系不通），放工作目录 |

## 工作区规矩

- 跑完管线执行 `organize.py <待粗剪目录>` 归位（1_原始/2_静音压缩/3_转录初选/4_粗剪成片/_工具）
- 修错表/决定应用前先 dry-run（select.py 内建，锚字不过整批拒绝）
- 跨文件重复不做自动检测（同场景重拍措辞不同，实测 sim 0.32 抓不到）——人工对读
- 初选决定走 select.py + 初选决定.json，不手写初选脚本；错拼沉淀 asr_fixes.json
- 依赖核验走 env_check.py，禁止手工逐个试

## 红线

- 只处理**用户自己的素材**（benchmark 子技能拉来的对标视频只调 asr_funasr.py 出转录稿，不进本流程），本流程自身不加任何爬取/下载他人视频的能力
- AI 初选一步到位直接出剪映草稿；品味判断后移到精剪
- 重依赖（torch 级）安装必须用户点头，不擅自装
- Cookie/敏感信息不进任何 git 跟踪文件
