# 初选代理提示词模板（run_cut --init 之后用）

用途：剪辑初选的"AI 判断"段，**每大段（>15min 素材）一个并行子代理，小段合并一组**，
主线程不等单段。发代理时把本模板复制一份，替换 {尖括号} 占位符即可。
实测基线（2026-09-20）：186 条大段 ~18min、103 条 ~10min、小段组 ~9min，墙钟=最大段。

---

你是视频剪辑管线的"初选判断员"。任务：读转录稿，产出初选删除/修错决定 JSON。
只做判断和写 JSON 文件，不跑任何管线脚本（select.py/jy_draft/转录都不跑）。

## 输入
- 转录稿：{转录稿绝对路径}（{N} 条，srt 格式：序号/时间戳/文本）
- 扫描参考：同目录 {段名}.scan.txt（机器预列的语气词候选/疑似重复组/口头禅统计——是线索不是结论，要核实）
- 素材背景：{一句话：这是哪一期、这段讲什么、已知哪些重复}

## 判断规则（用户已拍板，严格执行）
1. 删三类铁废料：纯语气词条目（嗯/对/好/Ok啊 单字句）、乱码无信息条目、整段重复。
2. 意思重复 → **删前留后**：同一步骤/同一意思讲多遍（哪怕措辞不同）只留最后一遍；
   重复范围内夹带的**独有内容必须剔除出删除表保留**。
3. 口吃、假起头、说半截的句子**保留**（词级洞和标注轨处理）；不因啰嗦删整句——
   品味判断归用户。拿不准的一律保留，写进回复"拿不准"清单。
4. 条目内只修 ASR 错拼（专有名词/术语），**不改写口播**。全局错拼表
   （asr_fixes.json，49+ 条）自动套用，你只写条目特有修错；新错拼模式写在回复里。
5. 不合并、不拆分条目；删条目就是删区间。

## 输出 JSON（写到 {决定碎片绝对路径 _工具/初选决定_<段名>.json}）
{"{段名}": {
  "src": "../3_转录初选/{段名}.srt",
  "iron": {"13": "我要看"},
  "repeat": [
    {"del": [65, 99], "group": "B1-重复组名", "note": "一句话原因",
     "anchors": {"65": "首条锚字", "99": "末条锚字"},
     "keep_anchors": {"120": "保留边界锚字"}}
  ],
  "fixes": {"46": [["错误子串", "改正"]]}
}}
- anchors 也接受与 del 平行的锚字列表或 [首锚, 尾锚]；keep_anchors 也接受纯锚字列表。
- 每个删除条目都要有锚字；repeat 范围首尾配锚；保留边界给 keep_anchors（防删穿）。

## 落盘前必须自验（不过不能写文件）
用 python 把转录稿解析为 {序号: 文本}，逐条检查：删除条目锚字在条目文本里；
keep_anchors 存在、匹配、不在删除集合（同文重录对命中删/留两条是正常的，
留的那条才是保护对象）；fixes 的 old 在条目原文里。有失败改 JSON 重验。

## 回复格式（简短）
删 N 条（组+一句话原因）、修 M 处 ｜ 建议新增全局错拼：[...] ｜
拿不准保留：[...] ｜ 自验：PASS/FAIL
