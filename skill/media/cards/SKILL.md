# cards · 录屏用 HTML 卡片

为视频生成插播信息卡：浏览器全屏打开 → 录屏 → 掐条进剪辑。定位是"口播之外的视觉层"，不是字幕、不是 PPT 课件。

## 什么时候用我 / 不用我

| 用 | 不用（换方案） |
| --- | --- |
| 症状→结论关键词卡、对照表、流程图、数字对比、时间轴示意 | 要跟口播节拍逐帧展开的动画 → Remotion/代码直出 mp4 |
| 空格分步的讲解卡（人控制节奏对口播） | 纯转场/特效 → 剪辑软件自带 |
| 清单/表格上屏 | 陈述句段落 → 那是口播的事，不做卡 |

**一条素材不做两版**：同一张卡只在 HTML / Remotion 里选一种落地。

## 分工铁律：画面字不重复口播

口播和画面文字逐字重复 = 让观众看字幕稿。画面上的字只允许做三件事：

1. **视觉化**——口播说"跟不上"，画面给时间轴上 AI 跑远、我卡半路
2. **召唤观众**——口播说"作为嵌入式新人"，画面问"屏幕前的你，是不是也是"
3. **留白提问**——清单第三格放"？"，答案让口播说

陈述句、数字细节、转折句永远归口播；画面字保留关键词级（≤10 字为主句）。

## 视觉规范（oil-cover 体系，横屏 1920×1080 基准）

- 底：暖白纸面 + 细网格 + 1-3 个邻近色 pastel 氛围层（雾蓝/藕粉/奶油，blur 大圆），禁黑底、霓虹、彩虹渐变
- 字：主标题深石墨超粗黑体；**衬线斜体只给英文/数字/等式**；强调用 pastel 圆角 chip 或字后低饱和高亮条
- 阴影：清爽浅阴影 `0 18px 44px rgba(30,35,40,.10)`，禁厚重黑影
- 可读性：主句 ≥80px（手机信息流缩放后仍可读）；每拍进场用 rise/drop 动画，禁一次全量平铺
- 自查：文字无重叠/无越界出画、chip 不换行孤字、氛围层不糊字、断行无孤字

## 交互形式（录屏对轴的关键）

- **分步卡（默认）**：`空格/点击 = 下一拍`，上一拍整体退场、同屏只有一拍；`R = 重来`；底部进度点。每拍对应口播一小句，念完按一下
- **自动卡**：CSS `animation-delay` 时间轴一次播完（≤8s），用于不需要对轴的短卡
- 页面自适应缩放：`fit()` 把 1920×1080 舞台 scale 到窗口，录屏窗口任意大小
- **鼠标光标保持可见**（录屏时移出画面即可）；F5 重播动画

## 工程结构

```
templates/卡.css           共享样式（色板/纸面/网格/chip/进场动画/fit 说明）
templates/分步卡模板.html   空格分步骨架（acts 数组 + 键盘/点击路由 + 进度点）
templates/自动卡模板.html   CSS delay 时间轴骨架
```

产出放项目的素材目录（如 `<视频项目>/01_字幕卡_HTML/`），一卡一文件，共享样式用相对路径引 `卡.css`（随卡复制一份）。

## 录制流程

Chrome 打开 → F11 全屏 → R 重置 → 按口播节奏走一遍排练 → 正式录（OBS/录屏软件），掐条留半秒余量 → mp4 进剪辑当普通素材。

## 红线

1. 画面字不做口播复读机（见分工铁律），验收时逐拍对照口播检查
2. 不为同一素材做 HTML + Remotion 两版
3. 卡上事实（数字、引脚、版本号）以实测/复盘勘误为准，写卡前先核
