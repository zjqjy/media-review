# draft · 大纲/脚本审阅工作台

```
选题池 ──AI 出初稿──▶ 初稿 md ──draft 网页审阅批注──▶ ✨清单喂 AI 改 ──▶ 定稿口播 md ──workbench──▶ 素材生产
```

替代「在对话里来回描述哪里要改」：意见直接打在稿子上，AI 拿到的是带定位的修改清单。

## 什么时候用我 / 不用我

| 用 | 不用（换方案） |
| --- | --- |
| AI 出的大纲/脚本要逐句改+给意见 | 还没初稿 → 先在对话里让 AI 出，落盘成 md 再来 |
| 批注攒一轮、AI 一次改完 | 素材生产 → workbench；剪辑 → cut |
| 改完的 md 要保持纯净喂下游管线 | 纯阅读批注不动稿 → 任何 md 阅读器 |

## 起服务

```bash
python scripts/draft_server.py [端口] [--dir 默认浏览目录]
```

→ 浏览器开 `http://127.0.0.1:8765/`（端口被占自动 +1）。纯标准库零依赖，前端自包含**无 CDN**（环境铁律）。只绑 127.0.0.1。

## 人工操作（网页）

- **打开**：路径输入回车 / 浏览弹层（按 mtime 列目录下 md）/ 最近文件
- **编辑**：点块直接改（contenteditable 按块隔离，中文 IME 安全）；悬浮工具条 ↑↓ 移动、✚ 插入、🗑 删除、💬 整块评论、⠿ 拖拽排序
- **批注四件套**：选中文字 → 浮动条 **删除/替换/评论/高亮**（markmark 思路）
- **批注面板**：↗ 跳转、✓已处理/重开、📍重锚（失锚批注置顶：点重锚再点目标块）
- **保存**：Ctrl+S；文件被外部改过会拦截（409），确认后可强制覆盖
- **✨ 复制给 AI**：待处理批注 + 分块全文打包成修改指令清单进剪贴板

## AI 配合流程（ZCode/Claude 生产剧本）

触发：用户说「审稿」「改稿」「大纲批注」「开工作台」

1. **定位初稿**：用户给 md 路径；AI 刚出的稿先落盘成文件（含 frontmatter 一起落）
2. **起服务**：后台跑 `draft_server.py --dir <初稿所在目录>`，把网址告诉用户
3. **等批注**：用户在网页里改字、打批注；批注自动落旁车文件
4. **改稿**：用户说「改稿」并贴 ✨清单（或直接读旁车 `.review.json`）→ 按意见修改 → **写回同一文件**，保持块结构与未提及内容原样，别丢 frontmatter
5. **复核闭环**：用户网页里重开（Ctrl+R）——改过的块若失锚会置顶提醒；确认无误点「全部已处理」
6. **定稿**：口播 md 交 workbench（`新视频项目.py` + 素材面板）

## 数据格式（红线）

- **md 本体永远纯净**：批注/高亮绝不写进 md（高亮只活 UI 层+旁车），下游管线照吃；写回 round-trip 逐字节保真（`tests/test_draft_blocks.py` 覆盖 CRLF/前后空行/围栏内假信号/嵌套列表/表格）
- **批注旁车** `<原名>.review.json`（如 `outline.md.review.json`）：

```json
{"version": 1, "comments": [{
  "id": "c1", "block_hash": "锚定键", "quote": "块内选中片段",
  "type": "comment|delete|replace|highlight",
  "suggestion": "replace 新文本", "note": "意见", "status": "open|resolved"}]}
```

- **锚定三级回落**：block_hash（`md5(type+"\0"+raw)[:10]`，前后端算法对齐已对拍）→ quote 全文找回 → orphan 置顶人工重锚；**绝不静默丢批注**
- **AI 直改是下期接缝**：✨清单格式（`[B#] (type)` 分块 + 编号意见）就是它的输入协议

## 已知边界（v1）

- 行内语法（**加粗**等）编辑时显示 md 源码形式，非富文本；表格/代码块整块源码编辑
- 同文重复块（相同列表项）hash 撞车锚到首个，批注打在重复块上时用 quote 区分
- 多人协作/云同步不做（本机单人文稿工具）
